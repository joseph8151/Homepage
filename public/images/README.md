# 사진 넣는 곳

이 폴더에 사진을 올리면 빌드 때 자동으로 배치됩니다. **파일명은 아무거나 괜찮습니다.**

- 가로 사진 → 홈 소개 큰 사진, 회사소개 큰 사진, 진행 과정 상단 와이드 사진 (순서대로)
- 세로 사진 → 홈 소개 세로 사진, 회사소개 세로 사진 (순서대로)
- 위치를 정하고 싶으면 `work-desk` / `laptop-beige` / `studio-black`(가로), `portrait-light` / `coffee-break`(세로)로 시작하는 이름을 쓰세요.
- 원본 그대로 올려도 됩니다(빌드 때 자동으로 웹용 크기로 줄임).
- 사진은 네이비 톤으로 통일되어 보이고, 마우스를 올리면 원래 색으로 돌아옵니다.
- 사진은 분위기 연출용입니다. 팀원·고객·후기로 오해될 이름·직함·인용을 붙이지 마세요. 설명 문구는 `content/photos.ts`에서 수정합니다.
