# 사진 넣는 곳

아래 파일명으로 이 폴더에 올리면 사이트에 자동으로 나타납니다(없는 파일의 구간은 표시되지 않음).

| 파일명 | 비율 | 표시 위치 |
|---|---|---|
| `work-desk.jpg` | 가로 | 홈 — 소개 섹션 큰 사진 |
| `portrait-light.jpg` | 세로 | 홈 — 소개 섹션 세로 사진 |
| `laptop-beige.jpg` | 가로 | 회사소개 — 큰 사진 |
| `coffee-break.jpg` | 세로 | 회사소개 — 세로 사진 |

- 원본 그대로 올려도 됩니다. Cloudflare 빌드 때 자동으로 긴 변 1800px·품질 82로 줄입니다(`npm run images`로 수동 실행도 가능).
- 모든 사진은 네이버 톤(흑백+네이비)으로 통일되어 보이고, 마우스를 올리면 원래 색으로 돌아옵니다.
- 사진은 분위기 연출용입니다. 팀원·고객·후기로 오해될 이름·직함·인용을 붙이지 마세요. 설명 문구는 `content/photos.ts`에서 수정합니다.
