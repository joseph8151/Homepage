# 사진 넣는 곳

이 폴더에 사진을 올리면 사이트에 자동으로 나타납니다. **파일명은 아무거나 괜찮습니다.**

- 가로 사진 2장 → 홈 소개 섹션 큰 사진, 회사소개 큰 사진
- 세로 사진 2장 → 홈 소개 섹션 세로 사진, 회사소개 세로 사진
- (파일명 알파벳순으로 배정됩니다. 위치를 정하고 싶으면 `work-desk` / `portrait-light` / `laptop-beige` / `coffee-break` 로 시작하는 이름을 쓰세요.)
- 원본 그대로 올려도 됩니다. Cloudflare 빌드 때 자동으로 웹용 크기로 줄입니다.
- 사진은 네이비 톤으로 통일되어 보이고, 마우스를 올리면 원래 색으로 돌아옵니다.
- 사진은 분위기 연출용입니다. 팀원·고객·후기로 오해될 이름·직함·인용을 붙이지 마세요. 설명 문구는 `content/photos.ts`에서 수정합니다.
